# Step 1 — Project Scaffolding

Goal: a runnable, empty Flask app with a working Tailwind v3 build pipeline.
No timer functionality yet — just the skeleton and a proof-that-it-works page.

## Tasks

1. **Create the project structure:**
   ```
   classroom-timer/
     app.py
     requirements.txt
     package.json
     tailwind.config.js
     static/
       src/input.css
       dist/output.css   (generated by the Tailwind build, but committed —
                           see note below)
     templates/
       index.html
     .gitignore
   ```

2. **Python side**
   - Create and activate a virtual environment (`venv`).
   - `requirements.txt` with Flask only (pin a recent stable version).
   - `app.py`: a minimal Flask app with a single `/` route that renders
     `templates/index.html`. Debug mode on for local dev.

3. **Tailwind side (npm-based, v3 — not the CDN version)**
   - `npm init` + install `tailwindcss@^3` as a dev dependency.
   - `tailwind.config.js` with `content` pointing at `templates/**/*.html`.
   - `static/src/input.css` with the three `@tailwind` directives.
   - An npm script to build `static/src/input.css` →
     `static/dist/output.css`, plus a `--watch` variant for local dev.

4. **`templates/index.html`**
   - Basic HTML5 skeleton, links `static/dist/output.css`.
   - Just enough content to visually confirm Tailwind is working (e.g. a
     centered heading with a Tailwind utility class or two). No timer UI
     yet — that's Step 2.

5. **`.gitignore`**
   - `venv/`, `node_modules/`, `__pycache__/`, `*.pyc`
   - **Do NOT gitignore `static/dist/output.css`.** This project commits
     the built CSS to version control, since the production server won't
     run an npm build step — it serves whatever's committed. Run the
     Tailwind build locally and commit the result whenever styles change,
     including right before deploying.

## Acceptance criteria
- `static/dist/output.css` is tracked in git (not ignored) and reflects
  the latest build — this is what production will actually serve.
- `flask run` serves the page at localhost, styled by Tailwind.
- Editing `input.css` or adding a Tailwind class to `index.html` and
  rebuilding visibly changes the page — confirms the pipeline works.
- No timer logic, no JS beyond what Tailwind's tooling needs. That starts
  in Step 2 (layout) and Step 3 (logic).
